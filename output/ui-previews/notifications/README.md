# Notification UI previews

Open index.html for the notification table, details.html for a full message, or dropdown.html for the expanded bell menu. These are standalone visual previews with sample messages, not live notifications. Filters and related-record destinations are layout demonstrations; no persistence or backend is connected.

The application changes consist of Razor templates, presentation models, CSS and a bell partial. No controller routes, retrieval, email worker or business-event changes were added. The live bell defaults to Notifications unavailable until the next implementation phase.
