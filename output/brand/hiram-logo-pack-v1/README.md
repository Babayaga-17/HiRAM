# HiRAM logo pack v1

Original direction: Borrow / Return. Two opposing paths bridge the uprights of an H: equipment leaves custody and returns. A custom, outlined HiRAM wordmark carries the identity. Designed for this system; no trademark or similarity clearance is claimed.

## Files

12 transparent SVGs: horizontal, stacked and standalone mark, each in primary, inverse, navy and white versions. All lettering is outlined paths; no font installation, embedded bitmap, external reference or script is required.

- Primary: cobalt #1D4ED8, tangerine #F97316, navy #17203A. Use on white or the existing #F7F9FF application ground.
- Inverse: light blue #93C5FD, light tangerine #FB923C, white. Use on the app's dark #0B1220 ground.
- Navy / white: single-color printing and small applications. White artwork is intentionally invisible on white.

Keep at least one upright's width of clear space around the visible artwork. Preserve proportions. Suggested minimum visible sizes: symbol 24 px, horizontal wordmark 140 px wide. Test the standalone mark in its actual favicon context before adopting at 16 px. Do not add gradients, shadows, stretch, recolor individual letters, or put the two-color primary logo on a low-contrast ground.

The pack is not installed in the application. Existing UI assets remain unchanged. The symbol is a designed H with directional bridges, rather than a stock package, shield or generic refresh badge.

Open preview.html for the family, use cases and a small-size check. Preview text uses system fonts; final SVG wordmarks are outlined.

Creation method: native SVG path construction; image generation was not used for this final vector pack.
